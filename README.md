# 特勤行动 · Tactical Squad

一个用纯 Canvas 写的 **2D 俯视角战术射击** 小游戏。单个 `index.html`，双击即玩，不依赖任何框架、不需要本地服务器。

## 怎么玩

直接双击 `index.html`（Chrome / Edge 都行）。
手机或平板：打开 Pages 网址后**把屏幕横过来**。

## 键位

| 操作 | 键 | 操作 | 键 |
|---|---|---|---|
| 移动 | `W A S D` | 开火 | 鼠标左键 |
| 开镜 | 鼠标右键 | 换弹 | `R` |
| 冲刺 | `Shift` | 静步 | `Ctrl` |
| 蹲 | `C` | 趴 | `Z` |
| 左下/右下侧身 | `Q` / `X` | 手电 | `F` |
| 投掷手雷 | `G`（按住出虚线预览） | 互动·开门 | `E` |
| 切枪 主/副/近战 | `1` / `2` / `3` | 检查弹药 | `V` |
| 背包（拾取·用药·换弹匣） | `Tab` | 小地图（全屏） | `M` |
| 暂停 / 设置 | `Esc` | 性能面板 | `F3` |

> 设置里可以改键、改画质、调音量、开关声纹与震屏。

## 有什么

- **视野**：200 条射线 + 墙角插入 + 软边，夜里 7 米 / 手电 30 米，雾只按距离叠不缩视野
- **声纹**：跑/走/静步/蹲四档音量，远处只给大致方向，AI 听到声音会来找你
- **战术 AI**：切派进房、掩体架枪、两人包抄、压制扫射、情绪（恐惧/犹豫/撤退）、头顶喊话气泡
- **枪械**：42 把真名枪、六类配件、倍镜（越大越难用）、护甲 1–6 级、子弹 1–6 级穿透、9 种特异弹可混装
- **经济**：交易行 → 仓库 → 背包/胸挂（都有格子限制）→ 出发；局内搜刮带出换钱
- **破坏**：玻璃、木箱、石头、砖墙分阶段裂开，打穿的洞子弹能过、人不能过
- **剧情**：入场动画（黑白胶片 14 秒）+ 简报 + 章节 + 结局；地图工坊可自建图
- **联机**：WebRTC 直连，房间码手动交换，1v1 / 2v2 / 占点 / co-op 清剿

## 存档

存档在浏览器本地（`localStorage`）。支持导出/导入存档文件，可以放进本仓库 `saves/` 当云存档，游戏里通过 CDN 读取。

## 技术

纯原生 JS + Canvas 2D，无依赖、无构建。音频是 WebAudio 程序合成 + 少量 wav/mp3 采样。
